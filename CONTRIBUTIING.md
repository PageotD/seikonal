# Contributing to seikonal

Thank you for your interest in contributing to `seikonal`!

## Workflow

1. All changes must go through a dedicated branch and Pull Request against `main`.
2. Follow [Conventional Commits](https://www.conventionalcommits.org/) for commit messages (e.g. `feat:`, `fix:`, `test:`, `docs:`).
3. Ensure that `task ci` passes locally before submitting a PR.
4. Adhere to Test-Driven Development (TDD) for numerical additions.
